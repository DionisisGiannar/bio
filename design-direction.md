# Bio design direction

Proposed direction: retro-futurist terminal interface with dithered pixel art and dark heraldic imagery.

This is a proposed visual direction, not an implemented website redesign.

## Vocabulary

- Retro-futurism: the overall imagined-future aesthetic.
- Terminal UI / TUI-inspired web design: monospace labels, command-like navigation, structured panels.
- Tactical sci-fi HUD / FUI (fictional user interface): fine rules, corner brackets, dossier layouts, restrained status indicators.
- Dithered pixel art: limited colors, visible square pixels, checkerboard shading.
- ASCII art: images constructed from text characters; distinct from pixel art.
- Dark heraldry: a useful descriptive term for the rabbit, crescent, swords, and family stars, rather than a precise historical classification.

## Suggested application

Use near-black or deep navy surfaces, warm off-white body text, and one primary accent such as phosphor cyan. Keep body text readable; reserve pixel type for short labels and headings. Use the rabbit as the large hero emblem and derive a simpler rabbit-and-three-stars mark for small sizes. Present biography as a concise profile dossier and projects as clear, browsable records. Use restrained motion and avoid fake system warnings or decorative data that competes with actual content.

Reference: https://nousresearch.com — inspiration for visual hierarchy and atmosphere, not a template to copy.

## Rabbit concept

Preserve the original rabbit pose, crescent, and three slender sword motifs. Translate shading into crisp pixels and limited-palette dithering. Add exactly three clearly separated stars to symbolize family. The detailed version is intended as a hero emblem; it needs simplification before use as a favicon.

Generated using the built-in image generation tool. First concept only; no website integration has been performed.

Preserve the recognizable pose and crescent composition. Input 2 is only supporting inspiration for retro digital engraving treatment; do not reproduce its photo background or captions. Translate the rabbit into carefully drawn, crisp square pixels with limited-palette checkerboard dithering and engraved pixel shading, like a detailed late-1980s monochrome computer illustration. Main colors pale phosphor cyan with a few darker muted teal shading tones, suited to a near-black personal portfolio. Exactly THREE clearly separate five-point pixel stars arranged in a small arc above the rabbit between/around the upper crescent and ears, all easily countable and distinct from sword hilts. These three stars symbolize family and must read as deliberate emblem elements. Retain the three slender sword motifs from the original, simplify for legibility, no gore. Strong readable silhouette with refined interior texture. A single centered emblem, generous transparent margin, true transparent background. No text, no mockup, no background, no border, no extra stars, no glow, no soft airbrushing, no smooth vector edges.
